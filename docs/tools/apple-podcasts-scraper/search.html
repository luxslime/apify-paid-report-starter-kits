Search inputs

  • searchTerm — optional keyword search powered by the iTunes Search API. At least one of searchTerm, chartRequests, or lookupIds is required for a run. Store prefill: technology.
  • country — default ISO country code (for example us)
  • limit — maximum number of podcasts returned for search. Store prefill: 3.
  • includeEpisodes — also fetch recent episodes for each resolved podcast. Leave this false on the first paid run.

Leave chartRequests and lookupIds empty until the search dataset is useful. Returned show IDs or source URLs can be reused in chart or watchlist runs, or in the Category Benchmark starter.

What search rows contain

Store documentation lists show-level fields such as rowType (example: podcast_search_result), collectionId, showName, publisher, country, rank, sourceUrl, and fetchedAt. Search is catalog discovery; it does not by itself provide a full RSS episode archive.
