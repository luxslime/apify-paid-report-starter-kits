Search inputs

  • searchTerm — optional keyword search powered by the iTunes Search API. At least one of searchTerm, chartRequests, or lookupIds is required for a run.
  • country — default ISO country code (for example us)
  • limit — maximum number of podcasts returned for search
  • includeEpisodes — also fetch recent episodes for each resolved podcast. Store quickstart leaves this off.

The Store README recommends starting with one search term and one country so the first source check stays small. Returned show IDs or source URLs can be reused in chart or watchlist runs, or in the Category Benchmark starter.

Store README search example

Copied from the Actor Store README. Review live input schema on the Store page before running.

{
  "searchTerm": "founder podcast",
  "country": "us",
  "limit": 10,
  "includeEpisodes": false
}

What search rows contain

Store documentation lists show-level fields such as rowType (example: podcast_search_result), collectionId, showName, publisher, country, rank, sourceUrl, and fetchedAt. Search is catalog discovery; it does not by itself provide a full RSS episode archive.
