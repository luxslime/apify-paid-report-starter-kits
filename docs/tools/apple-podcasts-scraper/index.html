What the Actor accepts

At least one of searchTerm, chartRequests, or lookupIds is required. Optional fields documented on the Store page:

  • country — default ISO country code for search and lookup (for example us, gb, jp). Chart items can override country.
  • limit — maximum shows for search, and the default chart limit when a chart item omits its own limit
  • includeEpisodes — also fetch recent episodes for each resolved podcast
  • delivery — dataset or webhook
  • webhookUrl — used when delivery is webhook
  • dryRun — run without saving results or sending webhooks

Output fields (Store documentation)

  • rowType
  • collectionId
  • showName
  • publisher
  • country
  • rank
  • episodeTitle
  • sourceUrl
  • fetchedAt

Rows also include source URLs, fetch timestamps, warnings when a source is partial, and stable IDs when the workflow supports recurring change detection.
