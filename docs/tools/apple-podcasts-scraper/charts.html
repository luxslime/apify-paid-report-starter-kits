Chart inputs

  • chartRequests — optional array of Apple rankings requests. At least one of searchTerm, chartRequests, or lookupIds is required for a run.
  • Each item can include country, feedType, and limit.
  • Supported feedType values: podcasts, podcast-episodes.
  • If a chart item omits limit, the run-level limit is the default.
  • includeEpisodes — also fetch recent episodes for each resolved podcast. The Store chart example leaves this off.

The Store schema presents charts as a follow-on after a small search quickstart is already useful. First paid run: starter JSON. Public chart metadata is a snapshot of Apple rankings; it is not verified audience size or advertising advice.

{
  "chartRequests": [
    {
      "country": "us",
      "feedType": "podcasts",
      "limit": 25
    }
  ],
  "includeEpisodes": false
}

What chart rows contain

Store documentation lists rank alongside show fields such as collectionId, showName, publisher, country, sourceUrl, and fetchedAt. Rank values reflect the requested Apple feed, not an independent audience estimate.
