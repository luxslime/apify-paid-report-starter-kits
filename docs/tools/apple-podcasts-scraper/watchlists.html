Watchlist inputs

  • lookupIds — optional list of Apple Podcasts collection IDs resolved through the iTunes Lookup API. At least one of searchTerm, chartRequests, or lookupIds is required for a run.
  • country — default ISO country code for lookup requests
  • includeEpisodes — also fetch recent episodes for each resolved podcast. Leave this false unless episode rows are required.
  • dryRun — run without saving results or sending webhooks. Extra keys are rejected by the live input schema.

Collection IDs are the numeric segment in an Apple Podcasts URL. Search or chart rows that already include collectionId can seed this list. First paid run remains the search starter, not a watchlist.
