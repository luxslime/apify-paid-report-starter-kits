Output fields (Store documentation)

  • rowType — Store sample uses podcast_search_result for a search row
  • collectionId
  • showName
  • publisher
  • country
  • rank — filled on chart rows; the Store search sample sets this to null
  • episodeTitle
  • sourceUrl
  • fetchedAt

Rows also include source URLs, fetch timestamps, warnings when a source is partial, and stable IDs when the workflow supports recurring change detection. Search is catalog discovery; it does not by itself provide a full RSS episode archive. Rank values reflect the requested Apple feed, not an independent audience estimate.

Pricing and no-change runs

Store listing: From $10 per 1,000 results. Pay per event. Store README: $0.005 actor start and $10.00 per 1,000 dataset results ($0.01 per row). The default dataset is the billable surface. Empty unchanged watchlist runs should avoid dataset writes. Dry runs, validation-only runs, missing-key warnings, and unchanged recurring polls should not write payable default-dataset rows.
